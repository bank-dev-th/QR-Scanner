# 📱 QR Scanner — เครื่องสแกนคิวอาร์โค้ด

แอปเว็บสแกนคิวอาร์โค้ดที่ใช้งานง่าย เปิดลิงก์อัตโนมัติ ไม่ต้องติดตั้งแอปเพิ่มเติม

## ✨ คุณสมบัติ

- 📷 ใช้กล้องมือถือโดยตรง
- 🌐 เปิดลิงก์อัตโนมัติ
- ⏸️ หยุดกล้องอัตโนมัติ
- 🔦 รองรับไฟแฟลช
- 📋 คัดลอกข้อมูลได้
- 🔘 เปิด/ปิดออโต้เปิดลิงก์
- 🔒 ทำงานในเครื่อง ไม่ส่งข้อมูลไปที่ไหน
- 📱 รองรับมือถือทุกขนาดหน้าจอ

## 🚀 วิธีใช้งาน

1. ดาวน์โหลดไฟล์ `index.html`
2. เปิดด้วยเบราว์เซอร์ (Chrome, Samsung Internet, Edge)
3. อนุญาตใช้กล้อง
4. ชี้กล้องไปที่คิวอาร์โค้ด → อ่านผลลัพธ์ทันที

## 📖 คู่มือฟีเจอร์

| ปุ่ม/ฟีเจอร์ | ทำหน้าที่ |
|-------------|----------|
| 🌐 เปิดลิงก์อัตโนมัติ | เปิด/ปิดการเปิดลิงก์เอง |
| 🌐 เปิดลิงก์ทันที | เปิดลิงก์ทันที ไม่ต้องรอ |
| 📋 คัดลอก | ก๊อปปี้ข้อมูล |
| 🔄 สแกนต่อ | สแกนคิวอาร์โค้ดอีกครั้ง |
| 🔦 ไอคอนไฟฉาย | เปิด-ปิดไฟแฟลช |

## ⚠️ ข้อควรทราบ

- ✅ ต้องใช้ผ่าน HTTPS หรือ localhost เพื่อขอสิทธิ์กล้อง
- 🔦 ไฟแฟลชทำงานได้บนอุปกรณ์ที่รองรับ ส่วนใหญ่บน Android
- 📐 วางคิวอาร์โค้ดห่างกล้องประมาณ 15–30 ซม.
- 🔒 ข้อมูลประมวลผลในเครื่องของคุณทั้งหมด ไม่ส่งไปที่ไหน
